# 🏠 Boston Housing Price Prediction

A machine learning project focused on predicting house prices using regression models and real-world housing data.

---

## 📌 Project Overview

This project builds a complete machine learning workflow to predict house prices based on socio-economic and environmental features.  
It includes data preprocessing, exploratory data analysis,model training, and evaluation.

The objective is to develop an accurate predictive system for real estate price estimation.

---

## 🧰 Tech Stack

- **Language:** Python  
- **Libraries:** pandas, numpy, matplotlib, seaborn, scikit-learn  
- **Environment:** Jupyter Notebook / Google Colab  

---

## 🔄 Workflow Summary

### 1. Data Collection
The dataset used is the Boston Housing dataset containing information such as:
- Crime rate  
- Number of rooms  
- Accessibility to highways  
- Property tax rate  
- Socio-economic indicators  
- Median house price (target variable)  

---

### 2. Exploratory Data Analysis (EDA)
- Distribution of variables  
- Detection of outliers (boxplots)  
- Correlation analysis between features  


---

### 3. Modeling
Models used:
- Decision Tree Regressor  
- Random Forest Regressor  
- Gradient Boosting Regressor  

---

### 4. Evaluation
Metrics used:
- R² Score  
- Model comparison  

Results:
- Decision Tree: R² = 0.8580  
- Random Forest: R² = 0.8923  
- Gradient Boosting: R² = 0.9153  

✔️ **Best model: Gradient Boosting**

---

### 5. Prediction
- Generated predictions on test data  
- Compared actual vs predicted values  
- Visualized model performance
