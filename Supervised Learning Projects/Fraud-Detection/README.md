# Fraud Detection on Imbalanced Data

## 🎯 Objective
Detect fraudulent transactions in highly imbalanced financial datasets.

## 📊 Dataset
- Highly imbalanced (fraud cases <1%)
- Features: transaction amount, time, location

## 🛠️ Techniques Used
- **Resampling**: SMOTE, ADASYN
- **Algorithms**: XGBoost, Random Forest
- **Evaluation**: Precision-Recall curve, F1-Score

## 📈 Results
| Model | Precision | Recall | F1-Score |
|-------|-----------|--------|----------|
| XGBoost + SMOTE | 0.92 | 0.89 | 0.90 |
