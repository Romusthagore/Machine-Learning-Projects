# Credit Score Classification

## 🎯 Objective
Predict credit scores (Good, Standard, Poor) based on customer financial behavior.

## 📊 Dataset
- Features: payment history, credit utilization, loan amount, employment status
- Target: Credit Score (3 categories)

## 🛠️ Techniques Used
- **Preprocessing**: Label Encoding, StandardScaler
- **Algorithms**: XGBoost, Random Forest, Gradient Boosting
- **Validation**: Cross-validation, GridSearchCV

## 📈 Results
| Model | Accuracy | Macro F1 |
|-------|----------|----------|
| XGBoost | 86.5% | 0.85 |
| Random Forest | 84.2% | 0.83 |
